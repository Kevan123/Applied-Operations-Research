# Applied-Operations-ResearchCoursework for COMP 6925: Applied Operations Research at The University of the West Indies, St. Augustine.

## Author: Kevan Rajaram

This repository contains Python Jupyter notebooks covering mathematical formulations, optimization models, numerical solutions, and interpretations.

Topics include:

* Transportation and assignment problems

* Minimum spanning trees and network reliability

* Binary integer programming and resource allocation

## Running the Notebooks

Open a notebook in Google Colab and select Runtime → Run all. Package installation and setup steps are included in each notebook.

Prepared for academic coursework.
